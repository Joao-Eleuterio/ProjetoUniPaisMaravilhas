# Data Analysis — País das Maravilhas

Data-analysis project implemented in a Jupyter Notebook with multiple stages of dataset validation and transformation.

## Repository contents

- `Projeto-fase1.ipynb` — analysis notebook
- `dados_origem_alunos.csv` — source dataset
- `fase1-AllData.csv` — processed dataset
- `fase1-ValidData.csv` — validated records
- invalid-data outputs for rejected records
- project report

## Focus

- Python
- Jupyter Notebook
- data cleaning
- validation
- CSV processing
- exploratory data analysis

## Background

Academic data-processing project retained as an example of early data-analysis and dataset-quality work.
